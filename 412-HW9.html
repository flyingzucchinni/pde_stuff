D'Alembert's Formula

Use the ansatz $$u(x,t)=F(x-ct)+G(x+ct)$$ in the wave equation with initial conditions $$u(x,0)=f(x),\frac{\partial u}{\partial t}(x,0)=g(x)$$ to discover d'Alembert's formula.

Solution.

Using the ansatz $$u(x,t)=F(x-ct)+G(x+ct)$$ we have $$u(x,0)=F(x)+G(x)=f(x)$$ $$\begin{align*} \frac{\partial u}{\partial t}(x,t)&=\frac{\partial F}{\partial (x-ct)}\frac{\partial (x-ct)}{\partial t}+\frac{\partial G}{\partial (x+ct)}\frac{\partial (x+ct)}{\partial t}\\&=-cF'(x-ct)+cG'(x+ct) \end{align*}$$ Plugging in the initial condition yields $$\frac{\partial u}{\partial t}(x,0)=-cF'(x)+cG'(x)=g(x)$$ Using FTC we have $$\begin{align*} -cF(x)+cG(x)&=\int_a^xg(s)\,ds\\ G(x)-F(x)&=\frac{1}{c}\int_a^xg(s)\,ds \end{align*}$$ Solving these equations simultaneously, we have $$\begin{align*} G(x)&=\frac{1}{2}f(x)+\frac{1}{2c}\int_a^xg(s)\,ds\\ F(x)&=\frac{1}{2}f(x)-\frac{1}{2c}\int_a^xg(s)\,ds \end{align*}$$ And we can now solve for $u(x,t)$ $$\begin{align*} u(x,t)&=\frac{1}{2}f(x+ct)+\frac{1}{2}f(x-ct)+\frac{1}{2c}\int_a^{x+ct}g(s)\,ds-\frac{1}{2c}\int_a^{x-ct}g(s)\,ds \end{align*}$$ $$\boxed{u(x,t)=\frac{1}{2}f(x+ct)+\frac{1}{2}f(x-ct)+\frac{1}{2c}\int_{x-ct}^{x+ct}g(s)\,ds}$$

12.2.2

Solve $$\frac{\partial w}{\partial t}-3\frac{\partial w}{\partial x}=0$$ with $w(x,0)=\cos x$.

Solution.

Using the method of characteristics, we have $$\frac{d}{dt}w(x(t),t)=\frac{\partial w}{\partial t}+\frac{dx}{dt}\frac{\partial w}{\partial x}$$ It is then easy to see that if $$\frac{dx}{dt}=-3$$ then $$\frac{dw}{dt}=0$$ Therefore $w$ is constant. Integration yields $$x=-3t+x_0$$ Using the initial condition $$w(x,0)=\cos x$$ Since $w$ is constant along the characteristic $$w(x,t)=w(x_0,0)=\cos x_0$$ Therefore, using $x_0=x+3t$, we have $$\boxed{w(x,t)=\cos (x+3t)}$$

12.2.3

Solve $$\frac{\partial w}{\partial t}+4\frac{\partial w}{\partial x}=0$$ with $w(0,t)=\sin 3t$

Solution.

Using the method of characteristics, we have $$\frac{d}{dt}w(x(t),t)=\frac{\partial w}{\partial t}+\frac{dx}{dt}\frac{\partial w}{\partial x}$$ It is then easy to see that if $$\frac{dx}{dt}=4$$ then $$\frac{dw}{dt}=0$$ So $w$ is constant. Integration yields $$x=4t+x_0$$ So $w$ is constant on the line $(4t+x_0,t)$, which intersects $x(t)=0$ at $t=-\frac{x_0}{4}$, hence $$w(0,-\frac{x_0}{4})=\sin(3(-\frac{x_0}{4}))=\sin(\frac{-3x_0}{4})$$ Plugging in $$x_0=x-4t$$ we have $$\boxed{w(x,t)=\sin(\frac{-3(x-4t)}{4})}$$

12.2.4

Using the method of characteristics, we can write $$w(x,t)=w(x(t),t)$$ Differentiating with respect to $t$ yields $$\frac{\partial w}{\partial t}=\frac{\partial w}{\partial x}\frac{dx}{dt}+\frac{\partial w}{\partial t}$$ So $$\frac{dx}{dt}=c$$ And so $w$ is constant along characteristics defined by $$x=ct+x_0$$ For $x<t$ we use the initial data, for $x>t$ we use the boundary data. This gives $$ \boxed{w(x,t)=\begin{cases} f(x-ct)&x<ct\\ h(t-\frac{x}{c}&x>ct \end{cases}} $$

12.6.6

Consider the traffic flow problem $$\frac{\partial \rho}{\partial t}+c(\rho)\frac{\partial \rho}{\partial x}=0$$ Assume $u(\rho)=u_{\text{max}}(1-\frac{\rho}{\rho_{\text{max}}})$. Solve for $\rho(x,t)$ if the initial conditions are

a)

$$ \rho(x,0)=\begin{cases} \rho_{\text{max}}&x<0\\ \rho(x,0)=0 &x>0 \end{cases} $$

b)

$$ \rho(x,0)=\begin{cases} \rho_{\text{max}}&x<0\\ \frac{\rho_{\text{max}}}{2}& 0<x<a\\ 0 &x>a \end{cases} $$

Solution.

a)

Assuming $$u(\rho)=u_{\text{max}}(1-\frac{\rho}{\rho_{\text{max}}})$$ We have $$q=u\rho=u_{\text{max}}\left(\rho-\frac{\rho^2}{\rho_{\text{max}}}\right)$$ Hence $$c(\rho)=q'=u_{\text{max}}\left(1-\frac{2\rho}{\rho_{\text{max}}}\right)$$ This is the speed of the characteristics, the equations are then $$ x=u_{\text{max}}\left(1-\frac{2\rho}{\rho_{\text{max}}}\right)t+x_0 $$ Using the initial conditions, we see that $$ \begin{cases} x=-u_{\text{max}}t+x_0 & x<0\\ x=u_{\text{max}}t+x_0 & x>0 \end{cases} $$ The diagram looks something like this

Therefore we have $$u(x,t)= \begin{cases} 0 & x<-u_{{\text{max}}}t\\ ?&-u_{{\text{max}}}t<x<u_{{\text{max}}}t\\ u_{\text{max}}&x>u_{{\text{max}}}t \end{cases} $$ Assuming that we have fanlike characteristics of all slopes between $-u_{{\text{max}}}$ and $u_{{\text{max}}}$ emanating from $(0,0)$, we can solve for $\rho$ from $$x=u_{\text{max}}\left(1-\frac{2\rho}{\rho_{\text{max}}}\right)t \quad 0\leq\rho\leq\rho_{\text{max}} $$ $$\rho=\frac{\rho_{\text{max}}}{2}\left(1-\frac{x}{u_{\text{max}}t}\right)$$ Which yields the following solution: $$ \rho(x,t)=\begin{cases} 0 & x<-u_{{\text{max}}}t\\ \frac{\rho_{\text{max}}}{2}\left(1-\frac{x}{u_{\text{max}}t}\right)&-u_{{\text{max}}}\leq x\leq u_{{\text{max}}}t\\ u_{\text{max}}&x>u_{{\text{max}}}t \end{cases} $$

b)

Recycling our work from part (a), we see that the characteristics are defined by $$ x=u_{\text{max}}\left(1-\frac{2\rho}{\rho_{\text{max}}}\right)t+x_0 $$ Hence $$ \begin{cases} x=-u_{\text{max}}t+x_0 & x<0\\ x=x_0 &0<x<a\\ x=u_{\text{max}}t+x_0 & x>a \end{cases} $$ Solving for $\rho(x,t)$, we have $$ \rho(x,t)= \begin{cases} \rho_{max}&x<-u_{max}t\\ \frac{\rho_{max}}{2}&x>0\\ 0&x>u_{max}t+a \end{cases} $$ Using the idea of expansion waves, we have $$\boxed {\rho(x,t)= \begin{cases} \rho_{max}&x<-u_{max}t\\ \frac{\rho_{max}}{2}\left(1-\frac{x}{u_{max}t}\right)&-u_{max}t\leq x\le0\\ \frac{\rho_{max}}{2}&x>0\\ \frac{\rho_{max}}{2}\left(1-\frac{x-a}{u_{max}t}\right)&0<x<u_{max}+a\\ 0&x>u_{max}t+a \end{cases}} $$

12.6.7

Solve the following problems:

a)

$$\frac{\partial \rho}{\partial t}+\rho^2\frac{\partial \rho}{\partial x}=0,\quad \rho(x,0)=\begin{cases} 3&x<0\\ 4&x>0 \end{cases}$$

b)

$$\frac{\partial \rho}{\partial t}+4\rho \frac{\partial \rho}{\partial x}=0,\quad \rho(x,0)=\begin{cases} 2&x<1\\ 3&x>1 \end{cases}$$

c)

$$\frac{\partial \rho}{\partial t}+3\rho\frac{\partial \rho}{\partial x}=0,\quad \rho(x,0)=\begin{cases} 1&x<0\\ 2&0<x<1\\ 4&x>1 \end{cases}$$

Solution.

a)

By inspection we have $$\frac{dx}{dt}=\rho^2$$ So $\rho$ is constant on the lines, we have $$x=9t+x_0$$ for $x<0$, and $$x=16t+x_0$$ for $x>0$. This is one of those cases where we don't have enough characteristics, hence $$ \rho(x,t)=\begin{cases} 3&x<9t\\ ?&16t<x<9t\\ 4&x>16t \end{cases} $$ Assuming that we have fanlike characteristics of all slopes between $9$ and $16$ emanating from $(0,0)$, we can solve for $\rho$ from $$x=\rho^2t$$ $$\rho=\sqrt \frac{x}{t}$$ Which yields $$\boxed{ \rho(x,t)=\begin{cases} 3&x<9t\\ \sqrt \frac{x}{t}&9t<x<16t\\ 4&x>16t \end{cases}} $$

b)

By inspection we have $$\frac{dx}{dt}=4\rho$$ So $\rho$ is constant on the lines, we have $$x=4t+x_0$$ for $x<1$, and $$x=6t+x_0$$ for $x>1$. This is also one of those cases where we don't have enough characteristics, hence $$ \rho(x,t)=\begin{cases} 3&x<8t+1\\ ?&8t+1<x<12t+1\\ 4&x>12t+1 \end{cases} $$ Assuming that we have fanlike characteristics of all slopes between $8$ and $12$ emanating from $(1,0)$, we can solve for $\rho$ from $$x-1=4\rho t$$ $$ \rho(x,t)=\begin{cases} 2&x<8t+1\\ \frac{x-1}{4t}&8t+1<x<12t+1\\ 3&x>12t+1 \end{cases} $$

c)

By inspection we see that $$\frac{dx}{dt}=\begin{cases} 3&x<0\\ 6&0<x<1\\ 12&x>1 \end{cases}$$ Hence $$\rho(x,t)=\begin{cases} 1&x<3t\\ 2&6t<x<6t+1\\ 4&x>12t+1 \end{cases}$$ For $3t<x<6t$, we solve using the equation $$x=3\rho t$$ And for $6t+1<x<12t+1$, we solve using the equation $$x=3\rho t+1$$ So $$\boxed{\rho(x,t)=\begin{cases} 1&x<3t\\ \frac{x}{3t}&3t<x<6t\\ 2&6t<x<6t+1\\ \frac{x-1}{3t}&6t+1<x<12t+1\\ 4&x>12t+1 \end{cases}}$$
